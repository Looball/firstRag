# 极光观测站值班手册

> 本文完全虚构，只用于 FirstRAG 教程检索练习。

极光观测站的内部编号是 `AURORA-417`。主控室位于北塔二层，备用记录册存放在南侧蓝色柜的第三层。

## 每日检查

1. 08:30 检查主传感器状态。
2. 12:00 记录云量等级。
3. 20:45 核对备用电池，最低安全电量为 68%。

## 故障约定

当风速连续十分钟超过 22 m/s 时，将外部天线切换到保护位置。恢复后使用验收短语 `POLAR WINDOW READY` 记录复位完成。
